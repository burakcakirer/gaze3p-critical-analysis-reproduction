# Assigned paper and dataset provenance

Elfares, M., Reisert, P., Küsters, R., & Bulling, A. (2025). *Gaze3P: Gaze-Based Prediction of User-Perceived Privacy*. arXiv:2507.00596v2. https://arxiv.org/abs/2507.00596

The revised source was consulted at https://arxiv.org/html/2507.00596v2, particularly Section 5, Tables 1/3 and Section 6.2.

Official public dataset resources identified:

- Authors' data page: https://www.collaborative-ai.org/research/datasets/Gaze3P/
- Public artifact identifier: https://doi.org/10.5281/zenodo.17104154

**Important:** The 100-participant gaze dataset was **not present** in the submitted original repository ZIP and was **not downloaded or analyzed** in this update. Any published paper metrics are explicitly cited as *paper-reported*. No original participants' gaze traces/images are stored in the repository. Please verify the original dataset's usage license before downloading it separately.
