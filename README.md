## Run the experiments

Use Python 3.10 or newer:

```bash
python -m pip install -r requirements.txt
python run_all.py
python -m unittest discover -s tests -v
```

All outputs are regenerated under `outputs/`. The sensitivity experiment uses three **synthetic** seven-level distributions, 300 runs per condition, 1,200 simulated user records per run, and either 0% or 20% probability of a bounded +/-1 rating perturbation. See `docs/REPRODUCTION_NOTES.md` and `src/extended_sensitivity_experiment.py` for the exact specification.

## Important: Which dataset was actually used?

**Neither the original participant-level Gaze3P dataset nor an original gaze feature file was included in the received ZIP.** The existing experiment and the new sensitivity results are entirely synthetic. Results quoted from the *published* Gaze3P dataset are explicitly marked as literature-reported results, not newly reproduced measurements.

The published Gaze3P data is linked at the [authors' data page](https://www.collaborative-ai.org/research/datasets/Gaze3P/) and the [Zenodo artifact](https://doi.org/10.5281/zenodo.17104154). Check the dataset's permitted academic uses before downloading, and do **not** commit private participant records or large copyrighted images to this repository.

For an approved and independently obtained CSV extract containing privacy ratings 1–7, run:

```bash
python src/dataset_ratings_summary.py --input /path/to/extract.csv --rating-col RATING_COLUMN
```

An optional `--group-col GROUP_COLUMN` produces group-level descriptive statistics. The actual Gaze3P file schema is **not assumed**; select the correct column names only after inspecting the original files. Real-data results are not included unless the genuine data is obtained and run by the student.
